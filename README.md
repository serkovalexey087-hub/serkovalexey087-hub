## 🎓 Дипломный проект: оптимизация процесса создания MVP с использованием ИИ

**Технологический стек:** `Python` `Streamlit` `Camunda` `LLM` `LangChain`

Создаю систему автоматизированной разработки MVP от разработки гипотезы сегмента до производства готового MVP через пайплайн независимых AI-агентов:

- ✅ **Модульная архитектура** — каждый агент принимает решения и передаёт результат следующему этапу
- ✅ **Визуализация процессов** — диаграммы BPMN для прозрачности бизнес-логики
- ✅ **Локальная обработка** — работа с русскоязычными моделями
- ✅ **Fallback-механизмы** — ручные процессы как резерв при сбоях

**Статус:** готов (но активно дорабатывается)
